✂️ Task 1 — Cutting & Editing Objects 45 min
Document setup: File → New → A3 Landscape · 420×297mm · 300 dpi · CMYK

The Three Tools

Object Selection (W)

Best for whole objects on clear backgrounds

  • Hover to preview blue highlight
  • Click or drag to select
  • Edit → Fill → Content-Aware
  • Shift/Option to add or subtract

Remove Tool (J)

Best for small marks and distractions

  • Shift+J to cycle to it
  • Brush over unwanted elements
  • AI fills the space automatically

Pen Tool (P)

Best for precise or complex edges

  • Click for straight points
  • Click + drag for curves
  • Alt/Opt to change curve direction
  • Right-click → Make Selection

Steps — click to expand

1
Prepare Your Document
▶
  1. File → New → A3 Landscape · 300 dpi → Create
  2. File → Place Embedded → choose your image → Enter
  3. Layer → Rasterize → Smart Object — now you can edit the image
Why rasterize? A placed image is a Smart Object. The Remove Tool and Fill will not work on it until you rasterize it.
2
Object Selection Tool
▶
  • Select Object Selection Tool (W)
  • Hover — blue highlight previews the selection
  • Click or drag to select
  • Edit → Fill → Contents: Content-Aware → OK — the object disappears
  • Deselect: Select → Deselect (or Cmd/Ctrl+D)
  • Shift+click adds · Option+click removes
3
Remove Tool
▶
  • Select Remove Tool (J) — or Shift+J to cycle
  • Adjust brush size to suit the element
  • Paint over unwanted areas — Photoshop fills automatically
4
Pen Tool — Precise Cutouts
▶
  • Select Pen Tool (P)
  • Click to place anchor points around your object
  • Click + drag for curves · Alt/Option to adjust curve direction
  • Close the path → Right-click → Make Selection

Steps — click to expand

1
Select Your Keywords
▶
  1. Choose 2–4 words or short phrases from your artist research
  2. Type Tool T → choose a font in the options bar → click on the page and type
  3. Try Andale Mono · Orator Std · Typewriter Condensed
Why keywords? Short phrases are easier to explore visually than long blocks of text.
2
Rasterize and Duplicate
▶
  1. Type → Rasterize Type Layer (or right-click the layer → Rasterize Type)
  2. Layer → Duplicate Layer → OK (or Cmd/Ctrl+J)
  3. Click the 👁 off on the original. Work on the copy.
Why? Text must be rasterized before filters work. The original stays safe underneath.
3
Create the Glitch
▶
  1. Rectangular Marquee Tool M — drag a thin strip across your word
  2. Layer → New → Layer via Copy (or Cmd/Ctrl+J)
  3. Move Tool V — press the arrow keys ← → to slide the strip a little
  4. Click the text layer again. Repeat with 3–5 strips.
Stuck?
· Nothing moves → in the Layers panel, click the new strip layer.
· Layer via Copy is grey → click the text layer first, then select again.
4
Wave Distortion
▶
  1. Layers panel: click the top strip, Shift + click the text copy → Layer → Merge Layers (or Cmd/Ctrl+E)
  2. Filter → Distort → Wave → move the sliders → OK
  3. Optional: Filter → Noise → Add Noise for texture
5
Integrate and Save
▶
  1. Position the glitch text in your A3 composition. Resize: Edit → Free Transform (or Cmd/Ctrl+T)
  2. File → Save As → Format: Photoshop (.PSD) → Save
  3. File → Export → Export As → JPG → Export → Desktop → Save
