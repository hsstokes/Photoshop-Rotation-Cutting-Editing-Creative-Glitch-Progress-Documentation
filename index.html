✂️ Task 1 — Cutting & Editing Objects 45 min
Document setup: File → New → A3 Landscape · 420×297mm · 300 dpi · CMYK

The Three Tools

Object Selection (W)

Best for whole objects on clear backgrounds

  • Hover to preview blue highlight
  • Click or drag to select
  • Delete → Content-Aware Fill
  • Shift/Option to add or subtract

Remove Tool (J)

Best for small marks and distractions

  • Shift+J to cycle to it
  • Brush over unwanted elements
  • AI fills the space automatically

Pen Tool (P)

Best for precise or complex edges

  • Click for straight points
  • Click + drag for curves
  • Alt/Opt to change curve direction
  • Right-click → Make Selection

Steps — click to expand

1
Prepare Your Document
▶
  • File → New → A3 Landscape · 300 dpi · CMYK
  • Edit → Fill → White background
  • File → Place Embedded to add your image
2
Object Selection Tool
▶
  • Select Object Selection Tool (W)
  • Hover — blue highlight previews the selection
  • Click or drag to select → Delete for Content-Aware Fill
  • Shift+click adds · Option+click removes
3
Remove Tool
▶
  • Select Remove Tool (J) — or Shift+J to cycle
  • Adjust brush size to suit the element
  • Paint over unwanted areas — Photoshop fills automatically
4
Pen Tool — Precise Cutouts
▶
  • Select Pen Tool (P)
  • Click to place anchor points around your object
  • Click + drag for curves · Alt/Option to adjust curve direction
  • Close the path → Right-click → Make Selection

Steps — click to expand

1
Select Your Keywords
▶
  • Choose a few words or short phrases from your artist research
  • Use Type Tool (T) — try Andale Mono · Orator Std · Typewriter Condensed
Why keywords? Short phrases are easier to explore visually than long blocks of text.
2
Rasterize and Duplicate
▶
  • Layers panel: right-click → Rasterize Type
  • Duplicate with Cmd/Ctrl+J — work on the copy, keep the original
3
Create the Glitch
▶
  • Use Rectangular Marquee (M) to select thin horizontal strips of text
  • Cmd/Ctrl+J to copy each strip to a new layer
  • Use Move Tool (V) to shift strips slightly left or right
4
Wave Distortion
▶
  • Merge strips: Cmd/Ctrl+E
  • Filter → Distort → Wave — adjust wavelength and amplitude
  • Optional: Filter → Noise → Add Noise for texture
5
Integrate and Save
▶
  • Position the glitch text within your A3 composition
  • Align with your artist study or research theme
  • Save as .PSD · export as .JPG
